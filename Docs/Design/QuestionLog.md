# Question Log

Every design question ever raised, in ID order, with its status and resolution. Open questions are also listed in [Open Questions](OpenQuestions.md).

- **Question** keeps the original wording, including any proposal made at the time, so the context behind each decision is never lost.
- IDs are assigned in order and never reused.
- **A question's wording is never edited.** If an answer settles only part of a question, the question is resolved with what was settled, and the rest becomes a new question with a new ID.
