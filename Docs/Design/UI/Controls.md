# Controls

**Status:** Draft

The game is played almost entirely with the mouse. The keyboard provides modifiers and hotkeys.

## No character movement

There is no walking or character movement. Travelling between zones, exploring and every other action is done by clicking.

## Mouse

| Input | Available |
|---|---|
| Left click, right click | Yes |
| Click and drag | Yes |
| Shift, Ctrl, Alt, and their combinations, with either button | Yes |

What each modifier combination does is defined per context as screens are designed ([OQ-032](../OpenQuestions.md)). Dragging in inventory grids is defined in [Drag and Drop](DragAndDrop.md).

## Keyboard hotkeys (defaults)

| Key | Opens |
|---|---|
| I | Inventory |
| M | Map |
| C | Crafting |
| S | Skills |

The rest of the keyboard is reserved for functional hotkeys of this kind. The full list grows as windows are designed.

## Accessibility

Baseline: [Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/full-list/), Basic tier ([GDD](../GameDesignDocument.md#pillars)).

- **All hotkeys and mouse bindings can be remapped** ("Allow controls to be remapped / reconfigured", Basic).
- Drag alternatives: [OQ-033](../OpenQuestions.md). Ideas to explore: click to pick up and click to place; double-click to move; click and hold to move many. Each method needs an alternative that requires neither a drag nor a held button (Intermediate tier).
