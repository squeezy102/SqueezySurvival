# In-game Wiki

**Status:** Concept - proposal from squeezy102's notes (2026-10-19), not approved. Marked by squeezy102 as a top-tier deliverable and a core pillar.

Everything the player needs to know lives in the game, not on a website.

## Rules

- **Only what the survivor knows.** Entries appear as things are discovered, so the wiki never reveals anything ahead of play ([You only know what you know](../GameDesignDocument.md#pillars)). It lets the player look back at everything learned so far.
- **Simple entries.** Organized, easy to navigate, never overwhelming. Plain information, no formulas.
- **Advanced entries** add the detail and the numbers, for players who want them. A checkbox in the wiki's header settings turns them on; off by default.
- **A Wiki button in the nav bar** opens it. Its icon is to be designed: the book is already Skills.

## Relationship to "the game tells you how it works"

That rule says every rule is stated where it applies ([GDD: pillars](../GameDesignDocument.md#pillars)). The wiki is where those explanations, and everything discovered, can be found again later.
