# Glossary

Canonical terms. Code, UI text and documents use these words with these meanings.

| Term | Definition |
|---|---|
| Action | Anything the survivor does. Has a duration, costs, requirements, outcomes and risks. See [Actions](Design/Systems/Actions.md). |
| Ambush | A forced combat encounter with no option to flee at the start. Only ambush predators the survivor has already seen in that zone can ambush, most often in the dark. See [Encounters](Design/Systems/Encounters.md#ambushes). |
| Bestiary | Record of encountered species, filling in with creature familiarity. See [Combat](Design/Systems/Combat.md#bestiary). |
| Biome | A category of environment (for example Beach) that defines which resources can be found. |
| Carrier | Equipment that adds its own weight-limited inventory, such as a basket, backpack or cart. See [Inventory](Design/Systems/Inventory.md). |
| Casual mode | A run option: free saving and loading (5 save slots plus the latest autosave), and death lets the player load a save. Earns no points. See [Runs](Design/Systems/Runs.md#run-options). |
| Challenge points | Earned per 30 days survived in a run; spent on unlocks that make the game harder. See [Runs](Design/Systems/Runs.md). |
| Combat | Turn-based fight with an animal, using hidden animal decks. See [Combat](Design/Systems/Combat.md). |
| Cost | What an action consumes: time, and optionally stats, materials or tool durability. |
| Creature familiarity | Per-species knowledge from encounters; unlocks combat tells and bestiary detail. |
| Day | 1,440 TU (24 hours of game time). |
| Day phase | One of six named parts of the day (Dawn, Morning, Midday, Afternoon, Dusk, Night) that other systems use to vary behavior. See [Time](Design/Systems/Time.md). |
| Decay | Deterioration of items over time, at a per-item rate, slowed by storage. Inorganic items decay very slowly. See [Decay](Design/Systems/Decay.md). |
| Dominant hand | Left or right, chosen at character select. It is the tool hand; the other hand is the offhand. See [Equipment](Design/Systems/Equipment.md#handedness). |
| Dry season | The hot season with little rain, in which an unattended fire can start a wildfire. See [Weather](Design/Systems/Weather.md#seasons). |
| Dud | An animal's combat card disabled by a successful hit; drawing it wastes the animal's turn. Lasts the whole fight. See [Combat](Design/Systems/Combat.md). |
| Easy mode | A run option that makes the game easier. Earns survival points at 1/5 value and no challenge points. Independent of casual mode. See [Runs](Design/Systems/Runs.md#run-options). |
| Encounter | A random wildlife event outdoors: thief, sighting, accident or discovery. See [Encounters](Design/Systems/Encounters.md). |
| Equipment slot | A place the survivor wears or holds an item: tool hand, offhand, head, neck, chest, belt, legs, shoes, gloves, two trinkets, back. See [Equipment](Design/Systems/Equipment.md). |
| Event log | The on-screen running record of game events in plain language. See [HUD](Design/UI/HUD.md#event-log). |
| Exertion risk | The chance that a strenuous action injures the arms or legs; zero above 50% stamina and rising as stamina falls. See [Exertion](Design/Systems/Exertion.md). |
| Exploration progress | A zone's explored percentage. Rises with each explore; milestones trigger significant discoveries. See [Exploration](Design/Systems/Exploration.md). |
| Feature pool | The weighted set of features an explore can reveal in a zone. |
| Find pool | The weighted set of loose items an explore can draw in a zone. |
| Food category | A grouping of foods such as Meat, Fish, Fruit, Vegetables or Dairy. Has its own tolerance meter. |
| Food tolerance | A per-food meter (100% to 0%) of how willing the survivor is to eat that food. Falls with each serving, recovers over time; low tolerance reduces what the food restores and causes penalties. See [Food](Design/Systems/Food.md). |
| Ground pool | The items lying on the ground in a zone. Unlimited in size; not part of the inventory. See [Zones](Design/Systems/Zones.md#ground-pool). |
| Hard mode | A run option that makes the game harder and earns double points. Cannot be combined with casual or easy mode. See [Runs](Design/Systems/Runs.md#run-options). |
| Hazard | A danger met while exploring, such as a jellyfish or sea urchin. |
| Health | Two-layer bar: current health (lowered by blows, restored by rest) under an injury ceiling (lowered by injuries). See [Injuries and Health](Design/Systems/Injuries.md). |
| Injury | A specific wound or condition (sprain, laceration, broken bone) that lowers the injury ceiling, has effects and heals over time. |
| Inventory | Items the survivor is carrying: the personal inventory plus any carriers. See [Inventory](Design/Systems/Inventory.md). |
| Known | Encountered by the survivor. Only known things are ever shown in the UI. |
| Light level | Bright, Dim or Dark. Derived from the day phase and light sources; gates and penalizes actions. See [Actions](Design/Systems/Actions.md#light-level). |
| Loadout | The set of gear the survivor is wearing and holding. Locked for the length of a fight. See [Equipment](Design/Systems/Equipment.md#loadouts). |
| Macro | Informal name for a survival stat. |
| Overshield | A stat that absorbs losses before they reach another. Contentment is Sanity's overshield. |
| Recipe | A definition of inputs, tools and time required to produce an item. |
| Research | The passive, time-based process that turns a topic into recipes. Topics are unlocked only by discovering a material. One topic at a time, with up to 3 queued. See [Research](Design/Systems/Research.md). |
| Resource node | A fixed zone feature harvested with actions, such as a banana tree or spring. Renewable actions let it replenish; destructive actions consume it. See [Resource Nodes](Design/Systems/ResourceNodes.md). |
| Run | One survivor's life, from waking on the beach to death. See [Runs](Design/Systems/Runs.md). |
| Shelter | Protection from weather: a shelter the player has built in a zone, or a sheltered sub-zone such as a cave. Automatically makes Wait, Rest, Nap and Sleep sheltered. See [Time](Design/Systems/Time.md#sheltered-variants). |
| Skill | The survivor's proficiency at an activity, such as melee fighting or first aid. See [Skills](Design/Systems/Skills.md). |
| Sub-zone | A smaller place inside a zone, such as a cave, with its own ground pool and features. Moving in and out is free. See [Zones](Design/Systems/Zones.md#sub-zones). |
| Survival points | Earned per day survived in a run; spent on perks and boosts. See [Runs](Design/Systems/Runs.md). |
| Survival stat | A core condition of the survivor shown as a bar where higher is always better, such as Food or Water. See [Survival Stats](Design/Systems/SurvivalStats.md). |
| Tell | A truthful combat hint. Rule-out tells eliminate one of an animal's three options; at mastery, explicit tells sometimes state its action. |
| Time unit (TU) | The smallest unit of game time: 1 minute. See [Time](Design/Systems/Time.md). |
| Tracking | A skill and action for finding an animal that escaped a fight. Injured animals are easier to track. See [Combat](Design/Systems/Combat.md#tracking). |
| Unattended fire | A fire burning while the survivor starts a full Sleep, or spends an hour or more in another zone. See [Weather](Design/Systems/Weather.md#wildfire). |
| Wardrobe building | A placeable building that stores whole gear sets for one-action swapping: stick dummy, wardrobe, armoire. See [Equipment](Design/Systems/Equipment.md#saved-loadouts). |
| Weapon class | Melee, Reach or Ranged. Decides which fighting skill applies and which of an animal's cards a hit turns into a dud. See [Combat](Design/Systems/Combat.md). |
| Weather state | The current island-wide weather, from Sunny to Hurricane. See [Weather](Design/Systems/Weather.md). |
| Wildfire | A disaster started by an unattended fire in the dry season. Gives a survivor in the zone 15-30 minutes to escape, and burns its organic resources and structures. See [Weather](Design/Systems/Weather.md#wildfire). |
| Zone | A discrete location belonging to a biome, connected to other zones. See [Zones](Design/Systems/Zones.md). |
| Zone connection | A discovered route from one zone into another. |
| Zone feature | A permanent or semi-permanent fixture of a zone revealed by exploring, such as a palm tree, tide pool or puddle. Resource nodes are zone features. See [Exploration](Design/Systems/Exploration.md#what-exploring-can-reveal). |
